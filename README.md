# Dombivali-Kalyan Ride App (Flutter UI Prototype)

A Flutter frontend prototype inspired by Uber/Ola-style flow for a geo-specific commuter app in the Dombivali-Kalyan region.

## Included flows
- Registration window
- Profile setup/view
- Ride booking (pickup + drop)
- Vehicle selection with fare display
- Driver matching simulation
- Trip completion with cash amount
- Post-ride rating trigger

## Theme
- Primary colors: **Golden** and **Dark Brown**

## Run
```bash
flutter pub get
flutter run
```
